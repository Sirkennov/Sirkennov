### 👨‍💻 About Me

I am a Full Stack Developer with over 3 years of experience building applications ranging from high-performance interfaces to critical payment gateways. I move fluidly between frontend and backend, focusing on writing clean, efficient code that remains stable under pressure. Dedicated Linux user and natural problem solver.

- ⚙️ **Backend & Architecture:** Experienced in designing robust server-side applications using **Go** and **TypeScript**, applying Hexagonal Architecture, Clean Code principles, and domain-driven design to ensure scalability and fault tolerance.
- 💻 **Frontend & Multiplatform:** Proficient in building dynamic SPAs and reactive user interfaces using **React**, **Vue**, and **Tailwind CSS**, alongside desktop and mobile solutions.
- 🗄️ **Databases & Systems:** Skilled in working with relational and non-relational databases (**PostgreSQL**, **MySQL**, **Redis**, **MongoDB**) and managing systems natively within **Linux** environments.
